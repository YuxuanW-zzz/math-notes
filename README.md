## 数学内容检查与校订

**校订日期：2026-10-05。** 已逐篇检查定义、定理条件、集合恒等式、证明依赖及关键公式，并同步更新合订本与分章 PDF。主要修订如下。

| 位置 | 发现的问题 | 修订 |
| --- | --- | --- |
| 课程 01 | 一维开集端点定义与有限分支的记号需更明确；标题有“可次加性”笔误 | 明确 `a<x`、`b>x`，说明有限指标情形，并修正为“次可加性” |
| 课程 02 | 下确界写成普通字母 `inf`；近似覆盖未注明有限外测度条件 | 改为数学算子，并明确该近似表述的适用条件 |
| 课程 03：补集封闭 | 提前断言可数个开集的交可测，而可数交封闭随后又依赖补集封闭 | 直接将该交的补集写为闭集的可数并，消除循环论证 |
| 课程 03：紧集可测 | 最后仅得到误差不超过 ε，而定义要求严格小于 ε | 从 ε/2 开始分配误差；说明有限个闭立方体与紧集不交时有正距离 |
| 课程 03：严格包含与可数可加性 | 对严格包含的解释不充分，可数可加性只陈述未指明证明位置 | 补充 Cantor 集非 Borel 子集与 Vitali 集的论证依据；指向课程 04 的证明 |
| 专题 06：近似覆盖与缩放 | 无限外测度时严格近似式不成立；零缩放可能写出未说明的 `0×∞` | 近似式限定有限外测度；非零缩放使用公式，零缩放单独处理 |
| 专题 06：矩形 | 一般区间乘积可能含退化或无界情形，直接相乘可能出现 `0×∞` | 明确该体积公式段落讨论有界非退化矩形 |
| 专题 07：连续性与缩放 | 将首项有限测度误称为每个具体序列的必要条件；未明确集合列可测性 | 明确它是保证一般结论的条件，可放宽为某一项有限；注明可测集合列，并单独处理零缩放 |
| 专题 08 | 将抽象可测空间中的可测集链接为 Lebesgue 可测集 | 区分“相对于给定 σ-代数的可测集”和“Lebesgue 可测集” |
| 专题 10：三进制与 Cantor 函数 | 含数字 1 不必在 Cantor 集外，端点有双重展开；不可数性论证缺少单射验证 | 补充端点例外、`1=0.222…₃` 与首次不同位的下界证明；用级数定义 Cantor 函数并说明区间端点取相同值 |

课程 04 的连续性、正则逼近和 Vitali 构造，课程 05 的水平集判别、极限、代数运算与简单函数逼近，以及专题 09 的 Borel 生成族与完备化论述，经本次检查未发现需要更改的数学结论。专题 10 的其余拓扑和测度性质保留。

## 记号与阅读约定

- `m*` 表示 Lebesgue 外测度，`m` 表示 Lebesgue 测度；默认维数 `d≥1`。
- 补集相对于所在全集取；函数水平集的补集相对于定义域取。
- a.e. 表示几乎处处；使用零测集修改时，依赖 Lebesgue 测度的完备性。
- 扩展实数运算需确认有定义；有限测度假设出现时不能直接消去。
- 课程 02 的 Cantor 构造以 `C₁=[0,1]` 起始，专题 10 以 `C₀=[0,1]` 起始；两者仅下标约定不同。
- PDF 中的“相关内容”是概念交叉引用；Vitali 集、Cantor 函数等已在相应章节中介绍，尚未另设独立专题。
