## 目录结构

```text
math-notes/
├── README.md
├── 实变函数/
│   ├── README.md
│   ├── 00-实变函数合订本.pdf
│   └── 01–10 分篇 PDF
└── 数值分析/
    ├── README.md
    ├── 00-数值分析合订本.pdf
    └── 01–03 分篇 PDF
```

## 文件命名

- 统一采用 `两位编号-内容标题.pdf`。
- `00` 为该学科的合订本，分篇文件从 `01` 开始按阅读顺序编号。
- 学科由所在文件夹区分，标题不重复添加学科前缀。
- 数值分析的编号表示阅读顺序，原课程周次在目录说明中保留。
- 每个学科的 README 列出完整目录、页数及下载链接。

## 阅读说明

先选择学科，再按该目录中的编号阅读。合订本适合连续阅读与打印，分篇 PDF 便于按主题查阅。PDF 保留已有笔记内容、公式、证明、例题及校注。
