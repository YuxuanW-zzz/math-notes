## 实变函数的记号与阅读约定

- `m*` 表示 Lebesgue 外测度，`m` 表示 Lebesgue 测度；默认维数 `d≥1`。
- 补集相对于所在全集取；函数水平集的补集相对于定义域取。
- a.e. 表示几乎处处；使用零测集修改时，依赖 Lebesgue 测度的完备性。
- 扩展实数运算需确认有定义；有限测度假设出现时不能直接消去。
- 课程 02 的 Cantor 构造以 `C₁=[0,1]` 起始，专题 10 以 `C₀=[0,1]` 起始；两者仅下标约定不同。
- PDF 中的“相关内容”是概念交叉引用；Vitali 集、Cantor 函数等已在相应章节中介绍，尚未另设独立专题。
